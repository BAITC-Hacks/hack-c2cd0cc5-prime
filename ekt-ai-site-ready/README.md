# Электрокомплект — витрина с ИИ-консультантом

Готовый стартовый сайт интернет-магазина электротоваров. Он показывает каталог,
фильтрует товары по категориям, ведёт локальную корзину и отвечает на вопросы
по каталогу через OpenAI API.

## Что входит

- `index.html` — адаптивная витрина и чат;
- `products.json` — демонстрационный каталог;
- `functions/api/chat.js` — Cloudflare Pages Function, которая безопасно
  вызывает OpenAI Responses API;
- `.gitignore` — не даёт случайно загрузить ключ в GitHub;
- `.dev.vars.example` — пример переменной окружения без настоящего ключа.

## Перед публикацией

1. Замените тестовые товары, остатки, цены и условия в `products.json`.
2. В `functions/api/chat.js` обновите такой же встроенный каталог: он нужен
   консультанту как контекст. Не публикуйте настоящие данные, пока не сверите
   их с поставщиком.
3. Корзина в этой версии работает только в браузере посетителя. Для приёма
   заказов подключите свою CRM, форму заявки или платёжную систему.

## Публикация через GitHub и Cloudflare Pages

1. Создайте новый репозиторий на GitHub и загрузите в него **содержимое этой
   папки**. Репозиторий может быть приватным.
2. В Cloudflare: **Workers & Pages → Create application → Pages → Connect to
   Git**. Подключите созданный репозиторий.
3. Выберите настройки: Framework preset — `None`; Build command — пусто;
   Build output directory — `/`.
4. После первого деплоя откройте **Settings → Environment variables** и
   создайте секрет `OPENAI_API_KEY`, вставив туда настоящий ключ OpenAI.
5. Выполните Redeploy. Ключ не попадёт в браузер и не должен появляться в Git.

Функция использует Responses API и Structured Outputs, чтобы возвращать чату
предсказуемый JSON. Для новых интеграций OpenAI рекомендует Responses API.

## Локальный запуск (необязательно)

Статичную часть можно открыть через любой локальный веб-сервер. Чтобы чат
работал локально, создайте `.dev.vars` по образцу `.dev.vars.example` и
запускайте проект средствами Cloudflare Workers/Pages. Никогда не публикуйте
`.dev.vars` и не передавайте ключ в клиентский JavaScript.
